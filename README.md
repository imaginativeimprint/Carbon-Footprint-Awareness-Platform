# Carbon Footprint Awareness Platform

An open-source API built to compute, analyze, and offset individual carbon footprints spanning travel, energy, and lifestyle food choices.

## Features
- **Accurate Calculations:** Computes individual metrics based on validated emission constants.
- **Actionable AI-driven Insights:** Returns localized suggestions to reduce emissions.
- **Secure by Design:** Built utilizing robust HTTP security headers via Helmet.

## Getting Started
1. Run `npm install` to load core dependencies.
2. Run `npm start` to initialize the Express application framework.
3. Run `npm test` to validate code functionality via Mocha.
